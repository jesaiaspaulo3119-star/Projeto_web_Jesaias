🟢 Página 1: index.html

Tela de Boas-Vindas

Foco: Navegação, hierarquia semântica e apresentação corporativa.

Desafio 01 Navegação
Adicione um atributo title="Página Inicial" ao link do menu de início no arquivo index.html.
Desafio 02 Acessibilidade
Insira o parâmetro lang="pt-BR" corretamente no elemento <html> e declare o charset="UTF-8" na tag head.
Desafio 03 Semântica
Substitua a tag <div> principal que envolve o conteúdo por uma tag semântica <main>.
Desafio 04 Layout/CSS
Crie um card com cor de fundo diferenciada chamando atenção para o horário de funcionamento da loja.
Desafio 05 Boas Práticas
Adicione uma mensagem de alerta no topo informando que o sistema é de "Uso Exclusivo de Funcionários".
Desafio 06 Imagens/CSS
Adicione uma imagem estilizada da logomarca da empresa usando caminhos relativos (ex: src="img/logo.png").
Desafio 07 Links Externos
Adicione um link no rodapé (<footer>) direcionando para o site institucional do sistema ERP parceiro.
Desafio 08 Estilização
Use pseudo-classes CSS (nav a:hover) para alterar o ponteiro do mouse e a cor dos botões de navegação ao passar o cursor.
Desafio 09 Organização
Crie uma seção com 3 cards lado a lado usando CSS Flexbox exibindo atalhos rápidos do sistema.
Desafio 10 Meta Tags
Inclua uma meta tag viewport configurada corretamente para compatibilidade com dispositivos móveis.

🟡 Página 2: produtos.html

Tabela de Estoque

Foco: Estruturação, manipulação visual e exibição de dados corporativos.

Desafio 01 Tabelas Semânticas
Agrupe as linhas da tabela utilizando estritamente as tags <thead>, <tbody> e <tfoot>.
Desafio 02 Mesclagem
Na linha de totalizador do <tfoot>, use a propriedade colspan para mesclar 4 colunas consecutivas.
Desafio 03 Indicadores Visuais
Adicione uma nova coluna chamada Corredor/Setor e classifique os produtos por local físico da loja.
Desafio 04 CSS Pseudo-Classes
Aplique o efeito de linhas zebradas em todas as linhas pares da tabela usando tbody tr:nth-child(even).
Desafio 05 Destaque Visual
Aplique o efeito tr:hover para destacar a linha inteira sobre a qual o ponteiro do mouse estiver posicionado.
Desafio 06 Badges de Status
Crie 3 classes CSS para etiquetar os produtos (.badge-verde, .badge-amarelo, .badge-vermelho).
Desafio 07 Alinhamento de Dados
Ajuste o alinhamento do texto para a esquerda no nome do produto e para a direita nas colunas numéricas de Preço e Quantidade.
Desafio 08 Inclusão de Registros
Adicione manualmente mais 3 produtos na tabela com dados realistas do mercadinho.
Desafio 09 Links Rápidos
Insira uma coluna de Ações na tabela contendo links estáticos chamados "Editar" e "Excluir".
Desafio 10 Scroll Responsivo
Envolva a tabela em uma div com classe .tabela-container para permitir rolagem horizontal em telas pequenas.

🔴 Página 3: cadastro.html

Formulário de Entrada

Foco: Validação nativa, entrada de dados e formulários corporativos.

Desafio 01 Organização
Agrupe os campos do formulário em dois blocos lógicos usando as tags <fieldset> e <legend>.
Desafio 02 Validação Nativa
Adicione o atributo required em todos os campos obrigatórios para impedir envios vazios.
Desafio 03 Tipagem de Inputs
Garanta que os campos de Preço usem type="number" com suporte a decimais via step="0.01".
Desafio 04 Campos de Seleção
Insira um campo do tipo <select> para escolher o fornecedor do produto.
Desafio 05 Feedback Visual
Estilize o evento input:focus no CSS para destacar o campo ativo com uma borda verde brilhante.
Desafio 06 Layouts com Flexbox
Alinhe o Preço e a Quantidade lado a lado em duas colunas usando display: flex.
Desafio 07 Controle de Datas
Adicione um campo de entrada do tipo date para a data de fabricação e validade do produto.
Desafio 08 Checkboxes
Adicione um grupo de caixas de seleção (checkbox) para indicar se o produto é Perecível ou Importado.
Desafio 09 Atributo Placeholder
Inclua dicas de preenchimento (placeholder) intuitivas em todos os campos de texto.
Desafio 10 Ação do Formulário
Configure o atributo action="produtos.html" para simular o redirecionamento após a gravação dos dados.

🎨 CSS Geral: style.css

Estilização Corporativa

Foco: Padronização visual, variáveis, resetação e suporte responsivo.

Desafio 01 Resets CSS
Crie uma regra universal * removendo as margens e paddings padrão de todos os elementos.
Desafio 02 Padronização Visual
Defina uma paleta de cores corporativa utilizando variáveis CSS (:root).
Desafio 03 Responsividade
Use @media (max-width: 768px) para transformar a navegação e o formulário em coluna única em celulares.
Desafio 04 Tipografia
Defina uma família de fontes limpa (Arial, sans-serif) com altura de linha espaçada para fácil leitura.
Desafio 05 Sombreamento
Aplique sombras sutis (box-shadow) nos cards e na tabela para passar uma impressão moderna.
